# Capas – Casa Vertigem

Cópias das capas do catálogo da livraria (Blogger), em WebP otimizado (600 px de largura).
O tema do site lê daqui pela CDN jsDelivr:

    https://cdn.jsdelivr.net/gh/vitorlimaid1-code/casa-vertigem-capas@main/capas/<arquivo>.webp

e, se ela falhar, direto do GitHub (raw.githubusercontent.com). Não renomeie nem apague arquivos da pasta `capas/`:
o nome de cada arquivo é o mesmo do cadastro original.

`capas/manifesto.json` lista as capas copiadas e as que não existiam mais no armazenamento original.
